**A. Teori HTML**
<br>
<br>
**1. Apa itu HTML ?**
 
HTML(Hyper Text Markup Language) adalah file yang kita akses ketika membuka website. HTTP request adalah permintaan untuk mengakses website yang di kirim ke server. 

**2. Struktur HTML terdiri dari :**
- HEAD
- BODY

**3. Heading dan Paragraph**
 
 Heading ini adalah sebuah judul atau subjudul yang memiliki ukuran font lebih besar dibandingkan Paragraph, Heading sendiri memiliki 6 Level, yang semakin rendah level nya semakin besar font nya.

 Paragraph sendiri itu digunakan untuk membuat paragraph dan memisahkan antara paragraph satu dengan yang lain. kemudian jika ada spasi yang lebih dari 1 secara berurutan maka ia akan di baca sebagai 1   spasi saja.

**4. Underline, Superscript, dan Subscript**
 
 Underline seperti nama nya ini digunakan untuk membuat teks memiliki underline.
 
 Superscript ini digunakan untuk membuat teks di dalam nya menjadi lebih kecil dengan posisi lebih ke atas, ini biasa digunakan di kuadrat misal E=MC^2
 
 Subscript ini kebalikan dari Superscript yakni ia membuat teks di dalam nya lebih kecil dengan posisi lebih kebawah, contoh nya seperti dalam penulisan CO2

**5. Line Break dan Horizontal Rule**
 
 Line Break ini diguakan ketika ingin memisahkan 2 teks yang tergabung dan meletakkannya tepat di bawah nya tanpa ada spasi di antara nya, tidak seperti pemisahan menggunakan paragraph.
 
 Horizontal Rule ini di gunakan untuk memisahkan 2 teks yang tergabung dengan menggunakan spasi dan garis Horizontal. 
 
**6. Strong, Emphasis, Blockquote dan Quote**
 
 Strong ini di gunakan untuk memperkuat teks di dalam nya, konsep nya sama seperti bold , bedanya sendiri strong di gunakan untuk elemen yang penting, serius dan darurat
 
 Emphasis ini digunakan untuk membuat teks di dalam nya jadi miring dan lebih tipis, mirip seperti italic. ini sama juga dengan cite ,tapi cite senditi di pakai untuk nama, title dari sesuatu seperti film, organisasi, dan samacam nya.
 
 Blockquote di gunakan untuk memisahkan teks di dalam nya dalam dari paragraph, ia akan lebih masuk ke kanan dan menggunakan seluruh block nya atau baris nya.
 
 Quote ini di gunakan untuk membuat teks di dalam nya menjadi quote , jadi teks nya akan dibungkus dengan tanda ""
 
**7. Abbreviation dan Acronym**
 
 Abbreviation dan Acronym ini di gunakan untuk menjelaskan kepanjangan dari suatu singkatan, dimana saat teks di hover maka akan ada pop up teks kepanjangan nya. untuk mengisi atau menampilakan kepanjangannya maka di dalam tag pembuka nya harus di tambahkan title="teks" 
 
**8. List**

 Ordered list digunakan untuk membuat list yang memiliki urutan angka secara berurutan. 
 
 Unordered list digunakan untuk membuat list tanpa ada urutan angka dan hanya ada point saja.
 
 Definition list diguakan untuk membuat list definisi, yang strukutur nya definisi list, definisi title, dan definisi nya.
 
 Pada list kita bisa membuat list di dalam list, misal kita dapat membuat Ordered list di dalam Unordered list.
 
**9. Link dan Multi Page**

 Link atau bisa disebut hyperlink, diguakan untuk action click untuk mengarahkan kita ke halaman lain, dengan mengatur href di dalam tag nya.

**10. HTML Atributes**

 HTML Atributes sendiri itu terletak didalam tag pembuka dalam HTML, contoh nya seperti style, href, title, id, dan semacamnya.
 
**11. Table**

 strukutur table di html itu table, table row(tr), table header(th) dan table data(td), untuk memperjelas table kita dapat menggunakan atribute border di tag table.

**12. Form**

 form di dalam nya kita memiliki input dan select, yang fungsi nya sama untuk mengisi data. 
 
 Untuk input sendiri ada berbagai type seperti button, text, password, radio, checkbox, dll.
 
 Untuk select kita memberikan opsi untuk user mengisi data yang sesuai.
